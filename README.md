# Travel-beyond
you are put on a habitable moon called Odysseus orbiting the gas giant Cileron in the star system Ziatania which is a G2V star similar to the sun though you are 17,000 light years away from the sun. If you find any bugs please tell me, the mod took me several months to make, it was primarily the custom textures I started finally making.
